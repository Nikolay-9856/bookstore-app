# «Полка» — веб-версия книжного магазина (кейс-задача № 4)

Python/Flask + SQLite. Два интерфейса: покупателя и администратора.

## Покупатель
- каталог книг с поиском, фильтрами (категория, автор, диапазон лет) и сортировкой по категории, автору, году написания, цене, названию;
- карточка книги с аннотацией, статусом и наличием;
- покупка или аренда на 2 недели / 1 месяц / 3 месяца (цена аренды = базовая × 1 / 1,8 / 4,5);
- «Моя библиотека»: купленные и арендованные книги, досрочный возврат;
- уведомления об окончании аренды.

## Администратор (`admin` / `admin123` — смените пароль)
- добавление, редактирование, удаление книг (книги с заказами снимаются с продажи, а не удаляются);
- управление ценой покупки и аренды, остатком и статусом прямо из таблицы;
- журнал аренд и отправленных напоминаний, ручной запуск проверки.

## Автоматические напоминания
При запуске `app.py` стартует фоновый поток, который раз в `REMINDER_INTERVAL` секунд (по умолчанию 3600)
ищет аренды, истекающие в течение `REMIND_DAYS_BEFORE` дней (по умолчанию 3), и просроченные аренды.
Каждое напоминание отправляется один раз: создаётся уведомление в личном кабинете и запись письма в `outbox.log`
(место для подключения SMTP).

## Запуск
```bash
pip install -r requirements.txt
python seed_demo.py   # необязательно: покупатель ivan / secret1 с арендами
python app.py         # http://127.0.0.1:5001
pytest -q
```
